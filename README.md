## 🧟 About the Project

This repository contains our implementation of a simplified—but extensible—version of **Plants vs. Zombies 2**.

The project is being developed as part of the **Advanced Programming course at Sharif University of Technology**.

Rather than building the entire game at once, development is divided into multiple incremental phases. Each phase introduces new systems, mechanics, and technical challenges while expanding on the architecture created in previous stages.

The early versions of the game are controlled through terminal commands. Later phases expand the gameplay systems, introduce graphics, and complete the remaining features.

---

## 🎯 Project Goals

This project is designed to help us practice and improve our understanding of:

* Object-oriented programming
* Clean and extensible software architecture
* Team-based software development
* Git workflows and version control
* Automated and manual testing
* Maintainable Java development
* Incremental feature development
* Collaborative problem-solving

Our goal is not only to make the game work, but also to build it using a structure that can evolve cleanly as the project grows.

## 🌱 Development Journey

```text
Terminal Gameplay
        │
        ▼
Core Game Systems
        │
        ▼
Expanded Mechanics
        │
        ▼
Graphical Interface
        │
        ▼
Complete Game Experience
```

The project progresses through several course phases:

### Phase 1 — Foundations

Development begins with the core domain model, terminal commands, and fundamental game logic.

### Phase 2 — Expansion

Additional gameplay systems and mechanics are introduced while the architecture is refined.

### Phase 3 — Graphics

The terminal-based experience evolves into a graphical implementation.

### Final Stages — Integration

The remaining systems are completed, tested, and integrated into the final game.
