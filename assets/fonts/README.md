# Fonts

**This folder is no longer used.** The interface takes its fonts from the
`pvz-skin` library, which bundles the real game faces (Burbank, Brianne's Hand
and House of Terror, including outlined variants) inside its jar.

The `.gitignore` beside this file is kept so that no font file can be committed
by accident. Any font files still sitting here are inert and safe to delete.

See `docs/documentation/ART_LIBRARIES.md` for how the skin's fonts are mapped.
